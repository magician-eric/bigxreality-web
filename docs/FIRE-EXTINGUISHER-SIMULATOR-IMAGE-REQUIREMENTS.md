# VR 虛擬滅火訓練系統 產品頁圖片素材需求清單

網址：`/tw/products/fire-extinguisher-simulator/`。頁面上共有 15 個圖片位置，目前都是依最終比例排好的預留區塊，公開頁面不顯示任何「待提供」字樣。
素材準備好後，只需要在內容檔（或 CMS 後台的「落地頁」欄位）填入圖片、替代文字、圖片說明、圖片類型與公開狀態，版面不會改變。

## 通用規格
- 格式：JPG 或 PNG（網站會自動轉成 AVIF／WebP）。寬度至少 1600 px；16:9 建議 1920×1080，4:3 建議 1600×1200，3:2 建議 1800×1200。
- 每張圖都要填「替代文字」。
- **圖片類型**：實際核准照片選「實際核准圖片」；情境示意圖選「情境示意圖」，網站會在右下角自動標示（不要把文字做進圖檔）。
- **公開狀態**：選「未核准」時原圖不會顯示、也不會進入部署內容，改用替代圖片或預留視覺。內部保密畫面與未核准的原始圖片請不要放進 Git 儲存庫。
- Hero 與操作照片的重點是實體鋼瓶、握柄、軟管與噴嘴操作；不得畫成學員雙手各持一支一般 VR 控制器。
- 軟體畫面（火災類型、滅火器種類、教學引導、測驗成果、火場）須為已核准的畫面；尚未核准的實際軟體截圖不得公開，可改用情境示意圖或設為「未核准」並提供替代圖片。
- 六個火場場景固定為住宅廚房、住宅客廳、辦公室、科技廠房、港口、鐵皮屋，不新增第七種。
- 圖中若有人物、單位標示、徽章或地點，請先確認可以公開使用。

## 如何填入圖片
1. 把已核准的圖片放進 `src/assets/images/products/`（檔名以 `fire-extinguisher-simulator-` 開頭）。
2. 在 `src/content/products/tw/fire-extinguisher-simulator.md` 對應位置的 `image`（Hero 是 `heroImage`）加上 `src` 與 `alt`；需要時加 `kind: illustration`、`status: withheld`、`substitute`。
