# 解決方案頁圖片素材需求清單

六個頁面：`/tw/solutions/military/`、`mum-t/`、`nova/`、`police/`、`fire-rescue/`、`smart-city/`。目前所有位置都是依最終比例排好的預留視覺，公開頁面不顯示「待提供」字樣。
素材準備好後，在內容檔（`src/content/solutions/tw/<slug>.md`）或 CMS 後台的「落地頁」欄位填入圖片、替代文字、圖片說明、圖片類型與公開狀態，版面不會改變。

## 通用規則
- 優先使用經核准的實際產品照片、訓練照片與系統截圖。涉及未完成架構或無法公開的畫面，使用概念圖或情境示意圖：圖片類型選「情境示意圖」，網站元件會在右下角自動標示「情境示意圖」（英文 Conceptual Illustration、日文 イメージ図 由各語言版的介面文字提供），不要把文字做進圖檔。
- 公開狀態選「未核准」時原圖不會顯示也不會進入部署內容，可另外提供替代圖片。內部保密畫面與未核准原圖不要放進 Git 儲存庫。
- 格式 JPG／PNG，寬度至少 1600 px；16:9 建議 1920×1080，3:2 建議 1800×1200，4:3 建議 1600×1200；每張圖都要填替代文字。
- 胸掛板必須符合實際設備外觀；NOVA 的概念圖不得描述成已完成的實際系統畫面。
