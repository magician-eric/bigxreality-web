## 通用規格
- 格式：JPG 或 PNG（網站會自動轉成 AVIF／WebP）。寬度至少 1600 px；16:9 建議 1920×1080，3:2 建議 1800×1200。
- 網站以「填滿裁切」方式顯示，主體請留在畫面中央。
- 每張圖都要填「替代文字」。
- 必須是實際的產品照片、系統畫面或實機錄影截圖；不使用圖庫照片或 AI 生成圖。
- 請使用實際機槍模擬設備及學員操作照片；不得使用實彈射擊照片冒充產品畫面，也不得與狙擊槍模擬系統的圖片混用。
- 不呈現後座力、彈道、自動評分、射擊紀錄分析或回放等未確認功能的畫面。
- 圖中若有人物、單位標示、徽章或地點，請先確認可以公開使用。

## 沒有素材時
任何位置都可以不放圖；移除該項的圖片位置後版面會自動調整。

## 如何填入圖片
1. 把圖片放進 `src/assets/images/products/`（建議檔名以 `machine-gun-simulator-` 開頭）。
2. 在 `src/content/products/tw/machine-gun-simulator.md` 對應位置的 `image`（Hero 是 `heroImage`）加上 `src` 與 `alt`；`need` 保留即可，圖片出現後就不會顯示。
