# 09｜搜尋意圖與 SEO 內容缺口（逐頁）

版本／方法：見 01。關鍵字搜尋量、排名、點擊、AI 引用：**尚無數據，無法驗證**（沒有 Search Console 或任何工具數據）。下表的「搜尋意圖」是依頁面主題推論的類型，不是實際查詢數據。
本文件只列建議與待補內容，不提供正式文案。英日的內容缺漏請見 03／04，這裡不重複列出，只寫 SEO 方面的影響。
問題類型代號：定義＝這是什麼；比較＝和替代方案或相似產品的差異；應用＝在什麼情境使用；採購＝導入條件、人數、空間、時間、配置、維護、報價流程。

## 三語共同建議（只列方向）
- 每個產品頁的 `<title>` 與 H1 都要包含產品正式名稱（見 T-07）。
- EN／JP 的 meta description 應依繁中完整副標或簡介撰寫，不要使用精簡版的一句話。
- 每個解決方案頁都可以參照產品頁 FAQ 的形式補問答（先寫繁中）。
- 不要為了 SEO 加入繁中沒有的功能或規格（原則 9）。
