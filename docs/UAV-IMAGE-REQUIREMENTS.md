# UAV 無人機戰術與反制無人機訓練系統 產品頁圖片素材需求清單

網址：`/tw/products/uav/`。頁面上共有 11 個圖片位置，目前都是依最終比例排好的預留區塊（顯示「素材需求｜…」）。
素材準備好後，只需要在內容檔（或 CMS 後台的「落地頁」欄位）填入圖片與替代文字，版面不會改變。

## 通用規格
- 格式：JPG 或 PNG（網站會自動轉成 AVIF／WebP）。寬度至少 1600 px；16:9 建議 1920×1080。
- 網站以「填滿裁切」方式顯示，主體請留在畫面中央。
- 每張圖都要填「替代文字」。
- 必須是實際的訓練照片、系統畫面或實機錄影截圖；不使用圖庫照片或 AI 生成圖。
- Hero 建議做成「實際學員操作＋模擬飛行畫面」的合成對照。
- 不得呈現干擾、攔截、接管或擊落等未確認的功能畫面；低空威脅畫面僅限實際存在的模擬情境。
- 圖中若有人物、單位標示、徽章或地點，請先確認可以公開使用。

## 不需要圖片的地方
- 訓練挑戰、導入價值：以文字與版面設計為主。
- 訓練流程：使用網站內建的線條圖示（目標、航線、情境變化、檢核）。
- 關聯產品與解決方案：圖片來自各自頁面的圖片。
- 核心訓練能力 03、05：文字列，不需要圖片。

## 沒有素材時
任何位置都可以不放圖；移除該項的圖片位置後版面會自動調整。

## 如何填入圖片
1. 把圖片放進 `src/assets/images/products/`（建議檔名以 `uav-` 開頭，例如 `uav-hero.jpg`）。
2. 在 `src/content/products/tw/uav.md` 對應位置的 `image`（Hero 是 `heroImage`）加上 `src` 與 `alt`；`need` 保留即可，圖片出現後就不會顯示。
