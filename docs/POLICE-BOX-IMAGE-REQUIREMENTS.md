# 攜帶式警勤訓練器（BOX） 產品頁圖片素材需求清單

網址：`/tw/products/police-box/`。頁面上共有 11 個圖片位置，目前都是依最終比例排好的預留區塊，公開頁面不顯示任何「待提供」字樣。
素材準備好後，只需要在內容檔（或 CMS 後台的「落地頁」欄位）填入圖片、替代文字、圖片說明、圖片類型與公開狀態，版面不會改變。

## 通用規格
- 格式：JPG 或 PNG（網站會自動轉成 AVIF／WebP）。寬度至少 1600 px；16:9 建議 1920×1080，4:3 建議 1600×1200，3:2 建議 1800×1200。
- 每張圖都要填「替代文字」。
- **圖片類型**：實際核准照片選「實際核准圖片」；情境示意圖選「情境示意圖」，網站會在右下角自動標示（不要把文字做進圖檔）。
- **公開狀態**：選「未核准」時原圖不會顯示、也不會進入部署內容，改用替代圖片或預留視覺。內部保密畫面與未核准的原始圖片請不要放進 Git 儲存庫。
- 請使用實際 BOX 箱體與學員操作照片。不得自行生成不符合真實產品的箱體結構、尺寸、開箱方式或設備配置。
- 不呈現具體架設時間、免校正、自動評分等未確認功能。
- 圖中若有人物、單位標示、徽章或地點，請先確認可以公開使用。

## 不需要圖片的地方
- 訓練挑戰、導入價值、訓練流程：以文字、圖示與版面設計為主。
- 核心能力 04、05：文字列，不需要圖片。
- 關聯產品與解決方案、實際應用案例：圖片來自各自頁面與案例的圖片。

## 如何填入圖片
1. 把已核准的圖片放進 `src/assets/images/products/`（檔名以 `police-box-` 開頭）。
2. 在 `src/content/products/tw/police-box.md` 對應位置的 `image`（Hero 是 `heroImage`）加上 `src` 與 `alt`；需要時加 `kind: illustration`、`status: withheld`、`substitute`。
