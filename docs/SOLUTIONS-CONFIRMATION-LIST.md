# 解決方案頁：待確認的功能與限制

以下內容確認前，網站不宣稱，也不會用推測內容填補。

## 警勤模擬
- 舊官網提過的生理監測、行動軌跡、心率、體溫與數位學習履歷，屬於特定系統或設備配置的能力。確認各產品（全配式、BOX）實際是否具備前，頁面只寫「適用系統的課程編輯、訓練紀錄與成果檢討」，不宣稱所有警勤產品均具備。
- 言語降級中由教官扮演或操作情境角色，需確認實際版本的配置。
- 全配式與 BOX 的確切差異（目前只區分完整場域部署與可攜式部署）。

## 軍事模擬
- 各軍事產品是否已與 MUM-T 或 NOVA 串接：網站不宣稱任何產品已完成串接。
- MUM-T：已知無人船影像可與 SUT 整合；其他無人載具的影像、控制或資料是否串接，需確認。胸掛板實際外觀與可公開照片。
- NOVA 目前以「聯戰模擬整合架構與解決方案」介紹；以下在確認前不寫成既有功能：所有軍事模擬產品即時連線、特定標準通訊協定、跨系統直接控制所有載具、大型聯戰實際部署、統一 AI 自動指揮、所有訓練資料即時同步。NOVA 不等同兵棋圖台，也不限於特定三項設備。

## 消防防災
- 內容依服務建議書的產品設計與規劃撰寫；量產或交付版本是否一致需確認，確認前不寫已驗收、已導入或已達成特定成效，也不當成成功案例。
- 不得宣稱多人連線、雲端管理、教官後台、智慧分析，或特殊火災物理、濃煙擴散、建築倒塌、即時災害預測。
- 舊官網提到的智慧消防救援、火場調查 VR 等歷史專案，不自動視為已上架的獨立產品。

## 智慧城市
- 沒有獨立對應產品，頁面採整合應用領域定位。能源／溫濕度／設備狀態整合、即時號誌控制、交通預測、資料介接、AIS、貨物流向、即時設備監測、即時災害預測與跨機關資料串接，均需依專案確認，不得寫成既有標準功能。
