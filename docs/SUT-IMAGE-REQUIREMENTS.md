# SUT 產品頁圖片素材需求清單

網址：`/tw/products/sut/`。頁面上共有 10 個圖片位置，目前都是依最終比例排好的預留區塊，會顯示「素材需求｜…」。
素材準備好後，只需要在內容檔（或 CMS 後台的「落地頁」欄位）填入圖片與替代文字，版面不會改變。

## 通用規格
- 格式：JPG 或 PNG（網站會自動轉成 AVIF／WebP 並產生多種尺寸）。
- 解析度：寬度 **至少 1600 px**；Hero 與 16:9 的圖片建議 1920×1080。
- 比例請依下表裁切；網站以「填滿裁切」方式顯示，主體請留在畫面中央。
- 每張圖都要填「替代文字」（描述畫面內容，給視障使用者與搜尋引擎）。
- 必須是 **SUT 實際的訓練照片、系統畫面或實機錄影截圖**。不使用圖庫照片、AI 生成圖或示意以外的畫面。
- 圖中若有人物、單位標示、徽章或地點，請先確認可以公開使用。
- 畫面上的文字（介面、標示）請清晰可讀；需要遮蔽的資訊請先處理。

## 不需要圖片的地方
- 訓練挑戰、導入價值：以文字與簡潔的版面設計為主。
- 訓練流程：使用網站內建的線條圖示（目標、團隊、情境變化、檢核），不需要圖片。每個階段日後若有合適的畫面，也可以個別加上 16:9 圖片。
- 關聯產品與解決方案：圖片來自 UAV、USV、軍事解決方案各自頁面的圖片。

## 沒有素材時
任何一個位置都可以不放圖。例如應用情境沒有專屬畫面時，移除該項的圖片位置後，版面會自動調整，不會留下空白。

## 如何填入圖片
1. 把圖片放進 `src/assets/images/products/`（建議檔名：`sut-hero.jpg`、`sut-approach-physical.jpg`、`sut-approach-virtual.jpg`、`sut-cap-formation.jpg`、`sut-cap-dynamic.jpg`、`sut-cap-xr.jpg`、`sut-scenario-cqb.jpg` 等）。
2. 在 `src/content/products/tw/sut.md` 對應位置的 `image`（Hero 是 `heroImage`）加上 `src`（圖片路徑）與 `alt`（替代文字）；`need` 保留即可，圖片出現後就不會顯示。
3. 英文、日文版的圖片位置沿用繁中版（圖片只填一次），替代文字再翻譯。
4. 用 CMS 的話，在後台「落地頁」欄位上傳圖片即可，不需要改檔案。
