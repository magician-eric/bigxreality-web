# 兵棋圖台系統 產品頁圖片素材需求清單

網址：`/tw/products/wargaming-table/`。頁面上共有 10 個圖片位置，目前都是依最終比例排好的預留區塊，公開頁面不顯示任何「待提供」字樣。
素材準備好後，只需要在內容檔（或 CMS 後台的「落地頁」欄位）填入圖片、替代文字與圖片說明，版面不會改變。

## 通用規格
- 格式：JPG 或 PNG（網站會自動轉成 AVIF／WebP）。寬度至少 1600 px；16:9 建議 1920×1080，3:2 建議 1800×1200。
- 網站以「填滿裁切」方式顯示，主體請留在畫面中央。
- 每張圖都要填「替代文字」；CMS 另有「對應區塊」「建議比例」「圖片說明」欄位。
- 必須是實際的產品照片、系統畫面或實機錄影截圖；不使用圖庫照片或 AI 生成圖。
- 必須是實際兵棋圖台設備、操作與系統畫面；不得標示或暗示符合特定軍事符號標準（MIL-STD）或已取得認證。
- 不呈現自動戰損計算、AI 戰術建議或自動報表等未確認功能的畫面。
- 圖中若有人物、單位標示、徽章或地點，請先確認可以公開使用。

## 不需要圖片的地方
- 訓練挑戰、導入價值：以文字與版面設計為主。
- 流程：使用網站內建的線條圖示，不需要圖片。
- 核心能力 01、04：文字列，不需要圖片。
- 關聯產品與解決方案：圖片來自各自頁面的圖片。

## 沒有素材時
任何位置都可以不放圖；移除該項的圖片位置後版面會自動調整。

## 如何填入圖片
1. 把圖片放進 `src/assets/images/products/`（建議檔名以 `wargaming-table-` 開頭）。
2. 在 `src/content/products/tw/wargaming-table.md` 對應位置的 `image`（Hero 是 `heroImage`）加上 `src` 與 `alt`；`need` 保留即可，圖片出現後就不會顯示。
