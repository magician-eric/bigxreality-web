# 關於 BXR：仍需公司提供的正式資料

網站只呈現公司實際核准公開的資料。下列資料提供並經確認前，對應頁面前台維持「沒有內容時的簡潔空狀態」（不進搜尋引擎、不進 sitemap），也不會出現虛構或「待提供」文字。資料請在 CMS 後台「關於 BXR」群組建立並發布。

## 發展歷程（CMS：發展歷程）
- 每個里程碑：日期（年或年月）、標題、說明，圖片選填。
- 需公司確認的歷史事實（成立時間、重要產品與專案、獲獎、參展等）；展覽、展示或媒體參訪不自動視為「導入案例」。

## 經營團隊（CMS：經營團隊）
- 同意公開的成員：姓名、職稱、簡介、照片（需本人同意公開）、排序。

## 合作夥伴（CMS：合作夥伴）
- 合作類型分三種：技術合作、系統整合、國際通路合作。
- 每個夥伴需先取得其公開授權，後台勾選「已取得合作夥伴公開授權」才會上線；未勾選不會出現名稱、Logo 或合作關係。名稱、Logo、說明、官方網址由夥伴確認。

## 投資人專區（CMS：投資人專區資料）
七個模組都已預留，只有「已發布至少一筆資料」的模組會出現在前台入口與模組選單。所有資料以公司實際核准公開的內容為準。

| 模組 | 需要的資料 |
|---|---|
| 公司基本資料 | 公司名稱、登記資訊、設立日期、實收資本額及其他正式公開的企業基本資訊（每項一筆：標題＝項目、說明＝內容） |
| 財務資訊 | 年度財務報告、營收資訊、相關文件（附件）；日期、分類（例：年報） |
| 公司治理 | 治理架構、董事會資訊、重要治理政策、相關公開文件 |
| 股東資訊 | 股東會資訊、股務公告、股利資訊、相關文件 |
| 重大訊息與公告 | 正式對外揭露的重要訊息、公告日期、附件 |
| 法人說明會 | 投資人簡報、說明會資料、相關影音或文件 |
| 投資人聯絡窗口 | 投資人關係聯絡資訊與正式洽詢管道 |

- **公司是否為上市、上櫃或公開發行公司，需先有正式資料確認**；確認前網站不會使用任何這類描述，也不會出現股票代號、財報、營收、董事名單、股利、股東會紀錄或法人說明會資料。
- 附件檔案請先上傳到可公開存取的位置（媒體庫或公司網站），再把網址填進附件；只放已核准公開的文件。
- 日期設為未來時，該筆資料會等到當天才顯示。

## 英文與日文
- 選單名稱中「關於 BXR」已有 About BXR、BXRについて；子選單與頁面文字尚待翻譯，翻譯版資料需另建同代稱的條目。
