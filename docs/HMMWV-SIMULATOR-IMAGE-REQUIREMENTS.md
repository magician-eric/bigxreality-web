# 悍馬車載具訓練系統 產品頁圖片素材需求清單

網址：`/tw/products/hmmwv-simulator/`。頁面上共有 10 個圖片位置，目前都是依最終比例排好的預留區塊，公開頁面不顯示任何「待提供」字樣。
素材準備好後，只需要在內容檔（或 CMS 後台的「落地頁」欄位）填入圖片、替代文字、圖片說明、圖片類型與公開狀態，版面不會改變。

## 通用規格
- 格式：JPG 或 PNG（網站會自動轉成 AVIF／WebP）。寬度至少 1600 px；16:9 建議 1920×1080，3:2 建議 1800×1200。
- 網站以「填滿裁切」方式顯示，主體請留在畫面中央。每張圖都要填「替代文字」。
- **圖片類型**：「實際核准圖片」直接顯示；「情境示意圖」由網站在圖片右下角自動加上「情境示意圖」標示（不要把文字做進圖片檔）。
- **公開狀態**：只有「公開」的圖片會出現在網站。選「未核准」時，原圖不會顯示也不會進入部署內容，改用「替代圖片」（會標示情境示意圖），沒有替代圖片就顯示預留視覺。
- **未核准的原始圖片請不要放進 Git 儲存庫**；請上傳到 CMS 媒體庫，或等核准後再提供。
- Hero 為「寫實情境示意圖」（軍用車輛駕駛模擬設備，學員坐在駕駛座、教官於旁指導），網站會自動標示「情境示意圖」。不得自行畫出未經確認的正式產品控制介面。
- 圖片以實際設備、駕駛訓練照片及非敏感情境示意圖交錯；不呈現駕駛評分、車輛故障模擬、自動記錄或回放等未確認功能。
- 圖中若有人物、單位標示、徽章或地點，請先確認可以公開使用。

## 不需要圖片的地方
- 訓練挑戰、導入價值、訓練流程：以文字、圖示與版面設計為主。
- 核心能力 02、05：文字列，不需要圖片。
- 關聯產品與解決方案、實際應用案例：圖片來自各自頁面與案例的圖片。

## 沒有素材時
任何位置都可以不放圖；移除該項的圖片位置後版面會自動調整。

## 如何填入圖片
1. 把已核准的圖片放進 `src/assets/images/products/`（建議檔名以 `hmmwv-simulator-` 開頭）。
2. 在 `src/content/products/tw/hmmwv-simulator.md` 對應位置的 `image`（Hero 是 `heroImage`）加上 `src` 與 `alt`；需要時加 `kind: illustration`、`status: withheld`、`substitute`。`need` 保留即可，圖片出現後就不會顯示。
