# 第一批：首頁 Hero 影片

只修改首頁影片元件、共用影片清單與專屬 QA，不包含其他頁面及文案調整。

- 既有兩支影片依序播放、結束換段、最後回到第一段；下一段開始播放後才交接，避免空白。
- 全部保留原始完整畫格。桌面文案與人物分區並加入邊緣漸層；平板及手機上方完整 16:9 影片、下方文案，手機沒有深色文字遮罩。
- 移除右下角可見播放按鈕，Tab 聚焦時顯示播放控制。減少動態效果預設使用靜態海報，不載入影片。背景分頁暫停，頁面切換清理監聽。
- `src/data/hero-clips.ts` 管理順序與不同影片的桌面／手機焦點。
- 原始 MP4／WebM／海報保持不變，沒有新增依賴、改網址、動 CMS 或其他頁面。

驗證命令：`npm run build`、`npm run check`、`node scripts/qa-home-video.mjs`。測試在此分支的獨立工作樹執行，避免其他未提交修改影響結果。

截圖位於本資料夾；before 為 main 原版，after 為本批。兩支影片桌面／手機均實際播放截圖；原始影格另外檢視 0.3／1.2／2.5 秒的人物與設備。手機屬 Chromium 模擬，實機 Safari／Android 仍待人工確認。
